## Flight Delay Predictor

A web app that takes in a user's flight information and predicts the likelihood of the flight being delayed. I trained the model from the ground up on flight and weather data, exported it to ONNX, and served it behind a .NET API deployed to Kubernetes.

## House Edge

Mobile app used to assist Casino Operations and Surveillance teams count cards. A session tracks the running and true count against decks remaining, logs each hand with its result and wager, and exports the session to a PDF — built in Kotlin with Jetpack Compose on oversized, glove-friendly controls for use on the floor.
